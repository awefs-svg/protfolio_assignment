## 로봇 청소기 경로 탐색 실습

- 수행 시기 : 2026년 4월 ~ 6월
- 진행 상태 : 완료

- 이동에 따른 배터리 소모 조건 적용
- 배터리 잔량에 따라 충전소로 복귀하는 조건 구현

### 사용 기술
- Python
- VS code
