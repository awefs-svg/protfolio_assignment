## Projects

기존 게임의 기능을 추가하거나 인공지능 알고리즘을 활용해 진행한 프로젝트들을 소개합니다.

각 프로젝트에서 구현한 주요 기능과 결과를 간단하게 정리했으며, 자세한 수행 과정은 상세 페이지에서 확인할 수 있습니다!


## JavaScript 기반 쿠키런 게임 아이템 기능 구현

### 활동 정보
- 수행 시기 : 2025년 10월 ~ 12월
- 진행 상태 : 완료
- 사용 기술 : JavaScript, Eclipse

### 프로젝트 소개
수업에서 제공된 쿠키런 게임을 기반으로 새로운 아이템을 추가하고, 아이템 획득에 따른 효과를 구현한 프로젝트입니다.

### 주요 구현 기능
- 새로운 아이템 이미지 추가 및 생성 확률 설정
- 랜덤한 위치에 아이템 생성되도록 구현
- 캐릭터가 아이템을 획득했을 때 효과 적용

### 구현 결과
설정한 확률에 따라 아이템이 생성되고, 캐릭터가 아이템을 획득하면 해당 효과가 적용되는 것을 확인했습니다.
