## 로봇 청소기 경로 탐색 실습

### 프로젝트 개요
장애물이 있는 환경에서 로봇 청소기가 목표 지점까지 이동하는 경로를 탐색하고, 배터리 상태에 따라 충전소로 복귀하도록 하는 실습 프로젝트입니다.

### 주요 구현 내용
- 무작위로 배치된 목표 지점까지의 이동 경로 탐색
- 장애물을 고려한 이동 경로 계산
- 이동에 따른 배터리 소모 조건 적용
- 배터리 잔량에 따라 충전소로 복귀하는 조건 구현

### 사용 기술
- Python
- VS code
