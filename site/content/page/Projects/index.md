## JavaScript 기반 2D 러닝 게임

### 활동 정보
- 수행 시기 : 2025년 10월 ~ 12월
- 진행 상태 : 완료

### 프로젝트 목적

### 본인 역할 및 주요 구현 내용
수업에서 제공된 게임 프로그램에 아래와 같은 기능을 직접 추가하고 테스트했습니다.

- 기존 게임에 새로운 아이템 생성 기능 추가
- 아이템 획득 시 적용되는 효과 구현

### 수행 과정
기존 게임의 코드 구조와 동작 방식을 살펴봤습니다. 이러한 분석을 바탕으로 기존 게임의 동작을 유지하면서 새로운 기능을 추가했습니다.

## AI 바둑 대결 실습

### 활동 정보
- 수행 시기 : 2026년 4월 ~ 6월
- 진행 상태 : 완료

### 프로젝트 목적
인공지능 수업에서 제공된 바둑 게임 프로그램을 기반으로, AI와의 대결에서 승리 가능성을 높일 수 있도록 구현하는 것을 목표로 했습니다.

### 본인 역할 및 주요 구현 내용
수업에서 제공된 바둑 게임 프로그램을 살펴본 후, 아래와 같은 기능을 직접 구현하고 테스트했습니다.

- 수 선택 전략에 적용할 가중치 설정
- AI와의 대결에서 승리 가능성을 높이기 위한 수 선택 전략 구현

### 수행 과정
제공된 바둑 게임 프로그램의 구조와 동작 방식을 살펴본 후, 상황에 따라 수 선택에 영향을 주는 조건에 가중치를 부여하는 전략을 구현했습니다. 이를 통해 여러 조건을 수치적으로 비교하고, 그 결과를 바탕으로 수를 선택할 수 있도록 했습니다.

### 구현 결과
가중치 기반으로 수 선택 전략을 적용한 바둑 게임 프로그램을 완성했으며 AI와의 대결 과정에서 직접 작성한 전략이 실행되는 것을 확인했습니다.

![AI 바둑 대결 실행 화면](/protfolio_assignment/images/AI_바둑대결.png)


### 학습 내용 및 개선 방향
여러 조건을 비교하고 상황에 따라 적절한 수를 선택하는 방법을 학습했습니다. 향후에는 다양한 수 선택 전략을 구성하고 각 전략에 적절한 가중치를 적용해 높은 성능을 지닌 AI와의 대결에서도 승리 가능성을 높일 수 있도록 개선하고자 합니다.

## 로봇 청소기 경로 탐색 실습

### 활동 정보
- 수행 시기 : 2026년 4월 ~ 6월
- 진행 상태 : 완료

### 프로젝트 목적
MDP를 활용해 장애물이 있는 환경에서 로봇 청소기가 이동할 행동을 결정하고, 배터리 상태에 따라 충전소로 복귀하도록 구현하는 것을 목표로 했습니다.

### 본인 역할 및 주요 구현 내용
수업에서 제공된 프로그램을 기반으로 아래와 같은 기능을 직접 구현하고 테스트했습니다.

- 로봇 청소기의 상태, 행동, 보상 설정
- Value Iteraion과 Policy Iteration을 활용한 행동 선택 정책을 계산
- 장애물을 고려한 이동 조건 적용
- 이동에 따른 배터리 소모 조건 적용
- 배터리 잔량에 따라 충전소로 복귀하는 조건 구현

### 수행 과정
먼저 로봇 청소시가 이동하는 환경을 상태와 행동으로 표현하고, 이동 결과에 따라 보상을 설정했습니다. 이후 Value iteration과 Policy Iteration을 구현해 각 상태에서 어떤 행동을 선택할지 계산하도록 했습니다.

또한 장애물과 배터리 소모 조건을 반영하고, 배터리 잔량이 부족할 때 충전소로 복귀하도록 동작을 구성했습니다.

### 구현 결과
MDP를 기반으로 Value iteration과 Policy Iteration을 구현해 로봇 청소기의 행동 선택 정책을 계산했습니다. 또한 실행 과정에서 장애물을 고려한 이동과 배터리 잔량에 따른 충전소 복귀 기능이 동작하는 것을 확인했습니다.

![MDP 기반 로봇 청소기 실행 화면](/protfolio_assignment/images/로봇청소기.png)

### 학습 내용 및 개선 방향
MDP를 활용하면서 상태, 행동, 보상 설정에 따라 로봇 청소기의 행동이 달라질 수 있다는 점을 학습했습니다. 향후에는 보상 설정을 다양하게 변경하고, 이동 효율과 배터리 소모를 비교해 더 효율적인 행동을 선택하도록 개선하고자 합니다.

### 사용 기술
- Python
- VS Code
