## JavaScript 기반 쿠키런 게임 아이템 기능 구현

### 활동 정보
- 수행 시기 : 2025년 10월 ~ 12월
- 진행 상태 : 완료

### 프로젝트 목적
JavaScript를 활용해 기존에 제공된 쿠키런 게임에 새로운 아이템을 추가하며 아이템 획득에 따른 동작을 직접 구현하는 것을 목표로 했습니다.

### 본인 역할 및 주요 구현 내용
수업에서 제공된 게임 프로그램에 아래와 같은 기능을 직접 추가하고 테스트했습니다.

- 새로운 아이템 이미지 추가 및 생성 확률 설정
- 설정한 확률에 따라 아이템이 랜덤한 위치에 생성되도록 구현
- 캐릭터가 아이템을 획득했을 때 적용되는 효과 구현

### 수행 과정
기존 게임의 코드 구조를 살펴보고, 아이템이 생성되고 캐릭터가 아이템을 획득하는 방식을 확인했습니다. 이후 새로운 아이템의 이미지를 만들고 아이템이 게임 화면에 생성될 확률을 설정한 다음 아이템을 획득했을 때 효과가 적용되도록 기능을 추가했습니다.

### 구현 결과
게임을 실행한 결과, 기존 게임에서 새롭게 추가한 아이템이 설정한 생성 확률에 따라 게임 화면의 랜덤한 위치에 생성되는 것을 확인했습니다. 또한 캐릭터가 해당 아이템을 획득했을 때 설정한 효과가 적용되는 것을 확인했습니다.

![쿠키런 게임 실행 화면](/protfolio_assignment/images/쿠키런_게임.png)

### 학습 내용 및 개선 방향
새로운 기능을 추가하는 과정을 통해 기존 코드를 이해하며 활용하는 방법을 학습했습니다. 향후에는 아이템의 종류와 효과, 시각적 이펙트를 다양하게 추가하여 게임의 기능을 확장하고자 합니다. 

### 사용 기술
- JavaScript
- Eclipse

## AI 바둑 대결

### 활동 정보
- 수행 시기 : 2026년 4월 ~ 6월
- 진행 상태 : 완료

### 프로젝트 목적
인공지능 수업에서 제공된 바둑 게임 프로그램을 기반으로, 공격과 방어 상황을 고려한 수 선택 전략을 구현해 AI와의 대결에서 승리 가능성을 높이는 것을 목표로 했습니다.

### 본인 역할 및 주요 구현 내용
수업에서 제공된 바둑 게임 프로그램을 살펴본 후, 아래와 같은 기능을 직접 구현하고 테스트했습니다.

- 자신의 돌을 연결하기 위한 공격 조건 설정
- 상대방의 돌 연결을 막기 위한 방어 조건 설정
- 공격과 방어 상황에 따른 가중치 설정 및 선택 전략 구현

### 수행 과정
제공된 바둑 게임 프로그램의 구조와 동작 방식을 살펴본 후, 
자신의 돌을 연결하는 상황과 상대방의 돌을 막아야 하는 상황을 구분하고 각 조건에 가중치를 설정했습니다. 이를 바탕으로 여러 후보 위치의 점수를 비교하며 점수가 높은 위치를 선택하도록 수 선택 전략을 구현했습니다.

### 구현 결과
가중치 기반으로 수 선택 전략을 적용한 바둑 게임 프로그램을 완성했으며 AI와의 대결 과정에서 직접 작성한 전략이 실행되는 것을 확인했습니다.

![AI 바둑 대결 실행 화면](/protfolio_assignment/images/AI_바둑대결.png)


### 학습 내용 및 개선 방향
여러 조건을 비교하고 상황에 따라 적절한 수를 선택하는 방법을 학습했습니다. 향후에는 다양한 수 선택 전략을 구성하고 각 전략에 적절한 가중치를 적용해 높은 성능을 지닌 AI와의 대결에서도 승리 가능성을 높일 수 있도록 개선하고자 합니다. 

### 사용 기술
- Python
- VS Code

## MDP 기반 로봇 청소기

### 활동 정보
- 수행 시기 : 2026년 4월 ~ 6월
- 진행 상태 : 완료

### 프로젝트 목적
MDP를 활용해 장애물이 있는 환경에서 로봇 청소기가 이동할 행동을 결정하고, 배터리 상태에 따라 충전소로 복귀하도록 구현하는 것을 목표로 했습니다.

### 본인 역할 및 주요 구현 내용
수업에서 제공된 프로그램을 기반으로 아래와 같은 기능을 직접 구현하고 테스트했습니다.

- 로봇 청소기의 상태, 행동, 보상 설정
- Value Iteraion과 Policy Iteration을 활용한 행동 선택 정책을 계산
- 장애물을 고려한 이동 조건 적용
- 이동에 따른 배터리 소모 조건 적용
- 배터리 잔량에 따라 충전소로 복귀하는 조건 구현

### 수행 과정
먼저 로봇 청소기가 이동하는 환경을 상태와 행동으로 표현하고, 이동 결과에 따라 보상을 설정했습니다. 이후 Value iteration과 Policy Iteration을 구현해 각 상태에서 어떤 행동을 선택할지 계산하도록 했습니다.

또한 장애물과 배터리 소모 조건을 반영하고, 배터리 잔량이 부족할 때 충전소로 복귀하도록 동작을 구성했습니다.

### 구현 결과
로봇 청소기 프로그램을 실행한 결과, 새로운 먼지가 생성되면 로봇 청소기가 장애물을 피해 이동하며 먼지를 청소하는 동작을 확인했습니다. 또한 이동 중 배터리 잔량을 확인하고, 배터리가 부족한 경우에는 충전소로 복귀하는 기능이 정상적으로 동작하는 것을 확인했습니다.

![MDP 기반 로봇 청소기 실행 화면](/protfolio_assignment/images/로봇청소기.png)

### 학습 내용 및 개선 방향
MDP를 활용하면서 상태, 행동, 보상 설정에 따라 로봇 청소기의 행동이 달라질 수 있다는 점을 학습했습니다. 향후에는 보상 설정을 다양하게 변경하고, 이동 효율과 배터리 소모를 비교해 더 효율적인 행동을 선택하도록 개선하고자 합니다.

### 사용 기술
- Python
- VS Code
