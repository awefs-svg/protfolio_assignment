## 활동 정보
- 수행 시기 : 2025년 10월 ~ 12월
- 진행 상태 : 완료

## 프로젝트 목적
JavaScript를 활용해 기존에 제공된 쿠키런 게임에 새로운 아이템을 추가하며 아이템 획득에 따른 동작을 직접 구현하는 것을 목표로 했습니다.

## 본인 역할 및 주요 구현 내용
수업에서 제공된 게임 프로그램에 아래와 같은 기능을 직접 추가하고 테스트했습니다.

- 새로운 아이템 이미지 추가 및 생성 확률 설정
- 설정한 확률에 따라 아이템이 랜덤한 위치에 생성되도록 구현
- 캐릭터가 아이템을 획득했을 때 적용되는 효과 구현

## 수행 과정
기존 게임의 코드 구조를 살펴보고, 아이템이 생성되고 캐릭터가 아이템을 획득하는 방식을 확인했습니다. 이후 새로운 아이템의 이미지를 만들고 아이템이 게임 화면에 생성될 확률을 설정한 다음 아이템을 획득했을 때 효과가 적용되도록 기능을 추가했습니다.

## 구현 결과
게임을 실행한 결과, 기존 게임에서 새롭게 추가한 아이템이 설정한 생성 확률에 따라 게임 화면의 랜덤한 위치에 생성되는 것을 확인했습니다. 또한 캐릭터가 해당 아이템을 획득했을 때 설정한 효과가 적용되는 것을 확인했습니다.

## 학습 내용 및 개선 방향
새로운 기능을 추가하는 과정을 통해 기존 코드를 이해하며 활용하는 방법을 학습했습니다. 향후에는 아이템의 종류와 효과, 시각적 이펙트를 다양하게 추가하여 게임의 기능을 확장하고자 합니다.
