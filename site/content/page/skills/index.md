## 프로그래밍 언어

### Python

<details>
<summary>Python</summary>
<p>Python을 활용해 DFS, BFS 등의 탐색 알고리즘을 구현했습니다. 알고리즘의 동작 원리와 탐색 과정에 따른 차이를 이해하고, 문제 해결에 적용하는 방법을 학습했습니다.</p>

<p>또한 MDP를 활용한 로봇 청소기를 구현하는 과정에서 상태, 행동, 보상을 설정하고 Value Iteration과 Policy Iteration을 구현했습니다. 이를 통해 로봇 청소기가 상황에 따라 행동을 선택하는 과정을 학습했습니다.</p>

</details>

### C

C언어의 기본 문법과 시스템 프로그래밍을 학습했습니다. Linux 환경에서 소켓 통신을 활용한 채팅 프로그램을 구현하며 네트워크 통신과 프로그램의 동작 과정을 경험했습니다.

### C++

C++의 기본 문법과 객체지향 프로그래밍 개념을 학습했습니다. 변수, 함수, 클래스 등의 개념을 익히고 프로그래밍 실습을 통해 문제 해결 능력을 기르고 있습니다. 

### Java

Java의 기본 문법과 객체지향 프로그래밍을 학습했습니다. Eclipse 환경에서 쿠키런 형태의 게임을 기반으로 아이템 생성과 같은 다양한 게임의 기능을 추가적으로 개발한 경험이 있습니다.

## 개발 도구
- **Eclipse** : JavaScript 프로그래밍 및 게임 개발 실습에 활용
- **VS Code** : Python 코드 작성, 프로젝트 파일 수정 및 웹 포트폴리오 개발에 활용
- **Linux** : 기본 명령어 사용과 소켓 통신 프로그램 실습에 활용
- **Git bash & GitHub** : Git 명령어를 활용한 소스 코드 버전 관리와 GitHub 저장소 관리 및 웹사이트 배포에 활용
